# 本机服务端口分配表（跨 Claude Code 会话共享）

> 用途：本机所有会 bind 端口的长驻服务在此登记，避免不同窗口/会话起服务时抢占同一端口。
> 维护规则见同目录 `SKILL.md`（skill `local-service-ports`）。
>
> **起服务前**：先查本表 → 该服务/项目已有端口就直接复用；没有就选一个「表里没占用 + 本机当前也没监听」的端口，登记后再起。
> **查端口是否空闲**：`Get-NetTCPConnection -LocalPort <端口> -ErrorAction SilentlyContinue`（有输出即被占用），或 `netstat -ano | findstr :<端口>`。
> **服务永久下线**：把状态改成「已释放」或删除该行，把端口让出来。
>
> 状态取值：`使用中` / `已释放` / `保留`
> 端口段轻约定（非硬性）：前端 `3000-3999` · 后端 API `8000-8999` · 数据库/中间件 `5000-5999` · 调试/杂项 `9000-9999`
